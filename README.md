# 🌾 Моя ферма

Браузерная игра в стиле Hay Day: грядки, животные, пекарня, деревня с картой, пропуск на 60 уровней,
мини-игры (рыбалка, шахта, колесо удачи, казино на виртуальные монеты), достижения, события и аккаунты.

Без сборки и зависимостей: чистые HTML + CSS + JavaScript (не C++).

## Запуск
Открой `index.html` в браузере или запусти любой статический сервер:

    python3 -m http.server 8000   # затем http://localhost:8000

## Публикация на GitHub Pages
1. Создай репозиторий и залей файлы.
2. Settings → Pages → Source: `main` / root.
3. Игра откроется по адресу `https://<имя>.github.io/<репозиторий>/`.

## Структура
- `index.html` — разметка
- `css/style.css` — оформление
- `js/game.js` — вся логика игры

## Сохранение
Прогресс пишется в `localStorage` (каждые 4 секунды, при сворачивании и закрытии вкладки, плюс резервная копия).
Аккаунты локальные; перенос между устройствами — «Код переноса» в профиле.
